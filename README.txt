PelviControl PWA

Installation iPhone:
1. Héberger les fichiers de ce dossier sur un site HTTPS.
2. Ouvrir l'adresse dans Safari.
3. Appuyer sur Partager.
4. Choisir « Ajouter à l’écran d’accueil ».
5. Ouvrir PelviControl depuis l’icône créée.

Important:
- Une PWA ne peut pas être installée correctement à partir d’un simple fichier local.
- Le service worker et l’installation hors ligne exigent un hébergement HTTPS.
